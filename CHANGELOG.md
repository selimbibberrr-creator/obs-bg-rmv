# Changelog

## 0.3.0 - 2026-06-30

### Added

- Native OBS effect filter and lifecycle management.
- Adaptive four-corner GPU background matte.
- Threshold, feather, edge shift and center protection controls.
- Spatial smoothing, motion-aware temporal stabilization and despill.
- Final, automatic and manual mask preview modes.
- OBS dock for per-filter mask editing.
- Erase, restore and protect brushes.
- Brush size, hardness and opacity controls.
- Undo, redo, clear, zoom, pan and fit controls.
- Persistent per-instance masks.
- Dutch and English localization.
- Windows x64 GitHub Actions build, artifact and tagged-release pipeline.
